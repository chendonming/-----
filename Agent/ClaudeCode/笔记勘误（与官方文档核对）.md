## 二、仍待处理的问题（当前笔记状态）

### A. `Claude Code 是否建议使用 codegraph 等 RAG 工具.md`

**A1 — 插件安装命名规律不精确（§三.2 / §五）**
- 现状："安装方式是 `/plugin install <语言>-lsp@claude-plugins-official`……"
- 核对：官方 `discover-plugins.md` 插件名**并非全部**符合 `<语言>-lsp` 规律：

  | 语言 | 插件名 | | 语言 | 插件名 |
  |---|---|---|---|---|
  | C/C++ | `clangd-lsp` | | Python | `pyright-lsp` |
  | C# | `csharp-lsp` | | Rust | `rust-analyzer-lsp` |
  | Go | `gopls-lsp` | | Swift | `swift-lsp` |
  | Java | `jdtls-lsp` | | TypeScript | `typescript-lsp` |
  | Kotlin | `kotlin-lsp` | | Lua | `lua-lsp` |
  | PHP | `php-lsp` | | | |
- 差异：**Go、Java、Python、Rust 不符合**该规律。示例 `typescript-lsp` 正确。
- 建议：改为"插件名见官方市场清单（如 `typescript-lsp`），统一加 `@claude-plugins-official` 后缀"。

**A2 — "约 180 个页面"（§一）**
- 现状："顺着全站文档索引（`llms.txt`，约 180 个页面）……"
- 核对：2026-08-04 实测 `llms.txt` 为 **174 个**文档 URL。"约 180"在可接受范围；如需精确可改"约 174"。

**A3 — "LSP 只作为'代码智能'出现在 large-codebases 与插件文档里"（§一）**
- 现状：见上。
- 核对：`how-claude-code-works.md` 的"代码智能"工具分类同样提及 LSP（"See type errors and warnings after edits, jump to definitions, find references (requires code intelligence plugins)"）。"只…出现在两处"不够精确。
- 建议：改为"主要出现在 `large-codebases` 与插件文档，另在 `how-claude-code-works` 的工具分类中被提及"。

### B. `Claude Code 提示词最佳实践.md`

**B1 — 首段翻译措辞（§一）**
- 现状："并在你观察、**纠正**或完全离开的情况下自主解决问题。"
- 官方原文："…autonomously work through problems while you **watch, redirect, or step away entirely**."
- 差异：`redirect`（引导/重定向）译成"纠正"略偏，不影响大意。可改"观察、引导或完全离开"。

**B2 — "两次以上" vs 官方 "more than twice"（§五）**
- 官方英文严格为"多于两次"（≥3 次），中文"两次以上"字面含 ≥2。差异极细微，中文口语中也常作"超过两次"解，可保留；如求严谨可写"超过两次"。

**B3 — 产品名错别字（§五，行 123）**
- 现状："**CLAUDE Code** 内置的 `/code-review` skill……"
- 差异：产品名官方写法是 "**Claude Code**"（Claude 大写、Code 词首大写），全大写 "CLAUDE" 是错别字。
- 附带核实：句中事实断言本身**正确**——`best-practices` 原文 "run the bundled `/code-review` skill, which reviews the current diff for bugs in a fresh subagent and returns findings to the session"，即"用全新 subagent 审查当前 diff"有官方原文支持，非推断。
- 建议：`CLAUDE` → `Claude`。

### C. `Claude Code 官方建议怎么用 subagent.md`

**C1 — 上下文节省量"约 1/15"（§二）**
- 现状："……大约 **1/15**。"
- 核对：按笔记自引数字，420 ÷ 6100 ≈ **6.9% ≈ 1/14.5**，不是 1/15。原文带"大约"，影响很小。
- 建议：改"约 **1/14.5**（约 6.9%）"，或保留并在脚注给精确值。

**C2 — 自定义 subagent 示例为"自拟示意"（§七）**
- 现状：示例 frontmatter `description: Reviews code for quality and best practices` / `tools: Read, Glob, Grep` / `model: sonnet`。
- 核对：字段值语法上**全部合法**（官方 quickstart 示例同为 `model: sonnet`），但官方 `Example subagents` 节的 code-reviewer 示例为 `tools: Read, Grep, Glob, Bash`、`model: inherit`。若代码块意图是"照抄官方格式"，与官方示例不一致。
- 建议：在代码块前注明"示例为自拟，非官方原文"，或改为官方原例。
